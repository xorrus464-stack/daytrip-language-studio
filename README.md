# 한마디 여행 · 영어와 일본어

여행 준비용 일본어·영어 학습 웹앱입니다. **`index.html` 파일 하나만 있으면** PC·휴대폰 어디서든 열려요.
(인터넷 없이도 대부분 동작하고, 기기에 일본어/영어 음성이 없을 때만 온라인 음성을 빌려 씁니다.)

## 여는 방법

- **PC**: `index.html`을 더블클릭 → 브라우저에서 바로 열립니다.
- **휴대폰**: 파일을 카카오톡 '나에게 보내기'나 클라우드로 옮긴 뒤, 파일을 눌러 Chrome/Safari로 열면 됩니다.
  (휴대폰 브라우저에서 열면 하단 탭 메뉴로 편하게 이동할 수 있어요.)

## 들어 있는 내용

| 메뉴 | 내용 |
| --- | --- |
| 일본어 첫 수업 | 히라가나 46자 + 가타카나 46자, 글자마다 **맞춤 SVG 연상 그림 · 연상 스토리 · 한국어/로마자 발음 · 듣기** |
| 필수 단어장 | 41개 단어(주어·명사 16 / 동사 13 / 형용사 12), **표기 3단 전환**(히라가나·가타카나·원래대로, 전체/카드별), 한자 카드(훈·음독·훈독·기억 팁), 그림, 듣기 |
| 자주 쓰는 문장 | 20문장(인사·카페·식당·길찾기·쇼핑·호텔·교통·일상), **표기 4단 전환**(히라가나·가타카나·원래대로·한자+후리가나), 상황 그림, 문법 포인트, 보통/천천히 듣기 |
| 영어 한마디 | 카페·식당·호텔·길찾기·쇼핑·공항 12마디 + 카페 주문 대화 4마디, 한국어 발음 표기, 보통/천천히 듣기 |

## 발음 듣기

- 모든 글자·단어·문장에 **듣기** 버튼이 있습니다. (문장은 **보통 1.0x / 천천히 0.85x**)
- 기기에 내장된 **일본어(ja-JP)·영어(en-US) 음성을 먼저** 찾아 재생합니다.
- 내장 음성이 없거나 음성 합성을 지원하지 않는 환경에서는 **자동으로 온라인 음성(Google)** 으로 넘어가고,
  화면에 "온라인 음성으로 재생" 안내가 뜹니다. 그래도 소리가 없으면 기기 **무음 모드**를 확인해 주세요.
- 왼쪽 아래(모바일은 메뉴 안)에서 기본 발음 속도를 보통/천천히로 바꿀 수 있습니다.

## 폴더 구조

```
daytrip-language-studio/
├── index.html          ← 완성된 단일 파일 (이것만 있으면 됩니다)
├── build.py            ← src/ 를 index.html 로 합치는 빌드 스크립트
├── src/
│   ├── shell.html      화면 뼈대
│   ├── styles.css      디자인(색·카드·반응형)
│   ├── data-ui.js      아이콘·대표 그림
│   ├── data-kana.js    히라가나 46 + 가타카나 46
│   ├── data-vocab.js   단어 41
│   ├── data-sentences.js 문장 20
│   ├── data-english.js 영어 12 + 대화 4
│   └── app.js          화면 렌더링·발음 엔진·상태 저장
├── preview/            미리보기 스크린샷
└── qa/                 자동 점검 스크립트(check.py, speech.py)
```

내용을 고칠 때는 `src/` 를 수정한 뒤 `python3 build.py` 를 실행하면 `index.html` 이 다시 만들어집니다.

## 확인된 것 (2026-11-21 기준)

- 모든 탭·필터·표기 전환·카드별 전환·후리가나 표시가 정상 동작
- 자바스크립트 오류 없음, 모바일 320/360/390px 가로 넘침 없음
- 음성: 내장 음성 선택(ja-JP=Kyoko, en-US=Samantha) → 취소 직후 재생 누락 복구 → 음성 없음 시 온라인 음성 폴백까지 자동 점검 완료
