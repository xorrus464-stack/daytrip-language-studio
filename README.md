# 한마디 여행 · 영어와 일본어

여행 준비용 **영어 · 일본어 학습 웹앱**입니다. **`index.html` 파일 하나만 있으면** PC·휴대폰 어디서든 열려요.
(인터넷 없이도 대부분 동작하고, 기기에 일본어/영어 음성이 없을 때만 온라인 음성을 빌려 씁니다.)

## 여는 방법

- **PC**: `index.html`을 더블클릭 → 브라우저에서 바로 열립니다.
- **휴대폰**: 파일을 카카오톡 '나에게 보내기'나 클라우드로 옮긴 뒤, 파일을 눌러 Chrome/Safari로 열면 됩니다.
- **홈 화면에 추가(PWA)**: 위쪽 오른쪽 `📲 홈 화면에 추가` 버튼을 누르면 안드로이드 크롬은 설치 창이,
  아이폰 사파리는 `공유 → 홈 화면에 추가` 안내가 뜹니다. 한 번 추가하면 주소창 없이 앱처럼 열려요.

## 들어 있는 내용

맨 위 **`🇺🇸 영어 | 🇯🇵 일본어`** 탭으로 학습 언어를 바꾸면, 홈·사이드 메뉴·하단 메뉴가 그 언어 코스로 바뀝니다.

### 오늘의 학습 — 질문(Q) + 대답(A) 세트

홈 화면 첫 블록이 **Q&A 세트**입니다. 여행지에서 실제로 오가는 **상대의 질문 + 내 대답**을 한 세트로 묶었습니다.

- **영어 4세트**: 카페 주문 · 식당 주문 · 공항 체크인 · 호텔 체크인
- **일본어 4세트**: 카페 주문 · 포장 여부 · 식당 주문 · 호텔 체크인
- 세트마다 **상황 장면 그림** → 상대 질문(발음·뜻·보통/천천히 듣기) → 내 대답(발음·뜻·듣기) → **핵심 바꿔 끼우기 팁**(예: `iced americano → a latte`, `これ → それ`)
- 일본어는 **원래 표기 / 히라가나** 전환과 한국어 발음 표기를 함께 제공합니다.

### 🇯🇵 일본어

| 메뉴 | 내용 |
| --- | --- |
| 가나 첫 수업 | 히라가나 46자 + 가타카나 46자, 글자 획 위에 **한국어 발음과 모양이 바로 연결되는 연상 그림**(あ=벌린 입, い=막대 둘, き=열쇠, く=쿠키 먹는 입 …) + 연상 스토리 · 한국어/로마자 발음 · 듣기 |
| 필수 단어장 | 41개 단어(주어·명사 16 / 동사 13 / 형용사 12), **표기 3단 전환**(히라가나·가타카나·원래대로, 전체/카드별), 한자 카드(훈·음독·훈독·기억 팁), 그림, 듣기 |
| 자주 쓰는 문장 | 20문장(인사·카페·식당·길찾기·쇼핑·호텔·교통·일상), **표기 4단 전환**(히라가나·가타카나·원래대로·한자+후리가나), 상황 그림, 문법 포인트, 보통/천천히 듣기 |

### 🇺🇸 영어

| 메뉴 | 내용 |
| --- | --- |
| 영어 한마디 | 카페·식당·호텔·길찾기·쇼핑·공항·교통 **19마디**, 단순 아이콘 없이 **문장 · 한국어 뜻 · 발음 · 보통/천천히 듣기** 중심 |
| 여행 영어 회화 | 7가지 상황(카페·식당·호텔·길찾기·쇼핑·공항·교통)에서 **상대와 나의 주고받는 회화 28줄** + **사람·소품·제스처가 그려진 상황 장면 그림** + 포인트 |
| 카페 주문 대화 | 주문부터 영수증까지 **6마디 대화**, 입구에 카페 카운터 장면 그림, 말풍선 대화 |

홈(`오늘의 학습`)은 선택한 언어에 맞춰 첫 카드·오늘의 한마디·추천 코스가 바뀝니다.

## 발음 듣기

- 모든 글자·단어·문장에 **듣기** 버튼이 있습니다. (문장은 **보통 1.0x / 천천히 0.85x**)
- 기기에 내장된 **일본어(ja-JP)·영어(en-US) 음성을 먼저** 찾아 재생합니다.
- 내장 음성이 없거나 음성 합성을 지원하지 않는 환경에서는 **자동으로 온라인 음성(Google)** 으로 넘어가고,
  화면에 "온라인 음성으로 재생" 안내가 뜹니다. 그래도 소리가 없으면 기기 **무음 모드**를 확인해 주세요.
- 왼쪽 아래(모바일은 메뉴 안)에서 기본 발음 속도를 보통/천천히로 바꿀 수 있습니다.

## 폴더 구조

```
daytrip-language-studio/
├── index.html          ← 완성된 단일 파일 (이것만 있으면 됩니다)
├── manifest.json       ← 홈 화면 추가(PWA) 설정
├── icon.svg            ← 앱 아이콘 원본
├── icon-192.png / icon-512.png / icon-180.png  ← 홈 화면 아이콘(PNG)
├── sw.js               ← 오프라인용 서비스 워커(네트워크 우선)
├── build.py            ← src/ 를 index.html 로 합치는 빌드 스크립트
├── src/
│   ├── shell.html      화면 뼈대 (상단 언어 탭·홈 화면 추가 모달 포함)
│   ├── styles.css      디자인(색·카드·반응형)
│   ├── data-ui.js      아이콘·대표 그림
│   ├── kana-glyphs.js  가나 92자 글자 윤곽(폰트에서 추출, tools/gen_glyphs.py)
│   ├── data-kana.js    히라가나 46 + 가타카나 46 (글자 윤곽 + 연상 그림, tools/gen_kana.py)
│   ├── vocab-art.js    단어 41개 장면 그림 (tools/gen_vocab_art.py)
│   ├── data-vocab.js   단어 41 (뜻·한자·훈독)
│   ├── data-sentences.js 문장 20
│   ├── data-english.js 영어 19 + 카페 대화 6 + 상황 회화 7 + 상황 장면 SVG
│   ├── data-qa.js      오늘의 Q&A 세트 (영어 4 · 일본어 4)
│   └── app.js          언어 전환·화면 렌더링·발음 엔진·설치 안내·상태 저장
├── tools/              그림·데이터 생성 스크립트 (gen_glyphs / gen_kana / gen_vocab_art)
├── preview/            미리보기 스크린샷
└── qa/                 자동 점검 스크립트
```

내용을 고칠 때는 `src/` 를 수정한 뒤 `python3 build.py` 를 실행하면 `index.html` 이 다시 만들어집니다.
아이콘은 `icon.svg` / `icon-180.png` 를 data URI 로도 넣기 때문에 `index.html` 단독 실행에서도 깨지지 않습니다.

## 확인된 것 (2026-11-21 기준)

- 오늘의 학습 **Q&A 세트**: 영어 4세트·일본어 4세트가 홈에 렌더링되고, 일본어는 원래 표기/히라가나 전환이 동작
- 가나 92자: 글자 윤곽(path) 위에 연상 그림이 겹쳐 그려지고, 카드마다 다른 스토리·색으로 표시됨
- 영어 한마디: 카드에서 단순 아이콘이 사라지고 텍스트·발음·듣기 중심으로 정리됨(19장 모두 그림 없음)
- 영어 상황 회화 7장면·카페 대화: 사람·소품·제스처가 있는 장면 그림 렌더링
- 모든 탭·필터·표기 전환·카드별 전환·후리가나 표시가 정상 동작
- 상단 `영어 / 일본어` 전환 시 홈·사이드 메뉴·하단 메뉴·오늘의 한마디가 함께 전환되고, 새로고침해도 선택이 유지됨
- 영어 19마디 + 카페 6마디 + 상황 회화 28줄에 각각 다른 SVG 그림이 렌더링됨
- 크롬 설치 가능성 점검(Page.getInstallabilityErrors) 결과 오류 0, 서비스 워커 등록·manifest·PNG 아이콘 모두 정상
- 자바스크립트 오류 0건(모든 화면 · 콘솔 오류 포함), 모바일 390px·태블릿 768px·데스크톱 1024/1440px 가로 넘침 없음, 단일 파일(file://) 실행 정상
- 음성: 내장 음성 선택(ja-JP=Kyoko, en-US=Samantha) → 취소 직후 재생 누락 복구 → 음성 없음 시 온라인 음성 폴백까지 자동 점검
